# Student Performance ML Model Comparison

## Project Overview

This project compares five Machine Learning classification algorithms using the StudentsPerformance dataset to predict student performance.

## Machine Learning Algorithms

- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Naive Bayes
- Decision Tree
- Random Forest

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- Macro F1 Score
- Confusion Matrix

## Model Comparison Results

| Model | Accuracy | Macro F1 Score |
|---|---:|---:|
| KNN | 67% | 57.12% |
| SVM | 67% | 52.69% |
| Naive Bayes | 71% | 57.75% |
| Decision Tree | 69.5% | 56.61% |
| Random Forest | 69.5% | 55.92% |

## Best Model

Naive Bayes achieved the highest accuracy of **71%** and Macro F1 Score of **57.75%** in the current experiment.
